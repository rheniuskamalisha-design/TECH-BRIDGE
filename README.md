# Tech Bridge AI — Frontend

A React + Vite frontend inspired by the supplied Tech Bridge video UI.

## Run
1. Install Node.js LTS.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the Vite URL shown in the terminal.

This version is frontend-only/demo mode. Login, roadmap, quiz, resume analysis, project search, jobs, mentor chat and profile interactions use local/mock state. The backend, MongoDB, Firebase and Gemini services can be connected later without replacing the UI architecture.
